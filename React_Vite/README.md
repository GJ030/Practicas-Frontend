# PROJECT_VITE

Proyecto base de **React 19** con **Vite 6**, creado con la plantilla inicial (`npm create vite`). Sirve como punto de partida para practicar componentes y estado con React.

## Estructura

- [`vite-project`](vite-project): aplicación React con ESLint configurado.

## Cómo ejecutarlo

```bash
cd vite-project
npm install
npm run dev
```
